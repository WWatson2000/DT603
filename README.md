README — Accreditation Expiry, Risk Analysis and ROI Modelling
Overview
I created this set of Python scripts to support data-driven decision making for the implementation of the Kallidus Learning Management System (LMS). The purpose of this work is to understand training compliance risk, future accreditation expiry trends, and the financial return on investment (ROI) associated with moving to a centralised, automated LMS.
The analysis focuses on accreditation expiry data (including PPST and First Aid), identifies which skills present the greatest operational risk, and quantifies the financial benefits of the system using a simple and transparent ROI model. All scripts are intentionally written at a clear, low-complexity level to ensure transparency and auditability.

Files in this :
DT603.py
This is the main analysis script. It:

- Loads accreditation data from data (6).xlsx
- Cleans and validates expiry dates
- Projects accreditation expiries over the next 18 months
- Produces monthly expiry counts
- Breaks expiry data down by accreditation title
- Identifies PPST-related accreditations
- Generates visual outputs (charts)
- Produces a simple linear trend forecast beyond known expiry dates
  regression.py
  This script performs a simple linear regression analysis on monthly expiry data to identify which accreditation is increasing fastest over time. It:
- Loads Monthly_expiring_by_title.csv
- Runs a separate regression for each accreditation
- Calculates slope, intercept and R² values
- Ranks accreditations by risk
- Identifies the highest-risk accreditation
- Plots actual values against the regression trend line
  ROI.py
  This script models the return on investment of the LMS implementation. It:
- Uses real project costs and savings from the business case
- Calculates yearly net impact
- Produces a cumulative cashflow view
- Estimates break-even timing
- Includes a simple 5-year NPV calculation at a 3.5% discount rate
- Allows conservative or full savings assumptions to be tested
  data (6).xlsx
  The source data file containing accreditation records exported from operational systems. This includes:
- Accreditation titles
- Accreditation expiry dates
- Accreditation status information
- Monthly_expiring_by_title.csv
- An intermediate output file generated by DT603.py, used by regression.py to analyse risk trends by accreditation type.
  Accreditation outputs/
  A folder containing all generated outputs, including:
- monthly_expiring_totals.csv
- monthly_expiring_by_title.csv
- ppst_monthly_expiring.csv
- Forecast files
- PNG charts showing trends and risk
- Requirements
  These scripts require the following Python libraries:
  pip install pandas numpy matplotlib openpyxl scikit-learn
  How to run the analysis
  Step 1 — Run the expiry and projection analysis
  python DT603.py
  This will:
- Read data (6).xlsx
- Generate all expiry projections
- Save CSV files and charts into the Accreditation outputs folder
- Step 2 — Run the regression risk analysis
  python regression.py
  This will:
- Load Monthly_expiring_by_title.csv
- Rank accreditations by trend risk
- Identify the highest-risk accreditation
- Display a regression chart
  Step 3 — Run the ROI model
  python ROI.py
  This will:
- Calculate net impact per year
- Show cumulative financial benefit
- Estimate break-even point
- Output a simple 5-year NPV figure
- What the outputs show (plain English)
  ROI outputs demonstrate that the LMS delivers financial benefit and supports strategic investment decisions

Data quality and limitations

- Rows with invalid or missing expiry dates are excluded from analysis.
- Forecasting uses a simple linear trend, not advanced time-series models.
- Regression analysis assumes linear growth for transparency and interpretability.
- ROI modelling uses conservative assumptions aligned with the business case.
